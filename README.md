# Social-Media-Engagement-Analysis-Using-SQL
This project focuses on analyzing social media engagement data using SQL. It explores user interactions, content performance, and engagement trends to understand audience behavior. The analysis helps identify patterns and generate meaningful insights to improve social media engagement.


## 📌 Project Overview

This project focuses on managing and analyzing social media activities using MySQL. It involves designing a relational database to store and manage information about users, posts, followers, likes, comments, and notifications. SQL queries are used to analyze user engagement, identify active users, calculate post-level interactions, and understand follower relationships.

## 🎯 Project Objectives

The objective of this project is to design and implement a relational database using MySQL to manage social media activities, including users, posts, followers, likes, comments, and notifications. It aims to analyze user engagement by retrieving post activities, calculating likes and comments, identifying active users, and examining follower relationships. The project also focuses on applying SQL concepts such as joins, aggregate functions, subqueries, Common Table Expressions (CTEs), user-defined functions, stored procedures, views, and triggers to efficiently manage and analyze social media data.

## ❓ Problem Statement

•  Design a relational database to organize social media users, posts, followers, likes, and comments.
•  Retrieve user and post details using SQL queries and filtering conditions.
•  Identify active users based on their post counts and follower activities.
•  Analyze post engagement by calculating total likes and comments for each post.
•  Evaluate user interactions by identifying users who liked or commented on posts.
•  Implement functions, subqueries, stored procedures, views, and triggers to simplify database operations and automate notifications.

## 🗄️ Database Design

The project uses the following five main tables:

| Table Name | Description |
|---|---|
| Users | Stores user details and account information. |
| Posts | Stores posts created by users. |
| Followers | Maintains follower and following relationships. |
| Comments | Stores comments made on posts. |
| Likes | Records likes received by posts. |

An additional **Notifications** table is created to store automated notification records generated by triggers.

## 📊 Tasks Performed

**1. Database & Table Creation**
- Created the SocialMediaDB database.
- Created tables using DDL commands.
- Modified table structures using ALTER and RENAME.
- Applied primary keys, foreign keys, and constraints.

**2. Data Manipulation & Filtering**
- Inserted sample users, posts, likes, comments, and follower records.
- Filtered users based on username and email domains.
- Retrieved posts within specific date ranges.
- Identified posts with NULL captions.

**3. Data Aggregation & Sorting**
- Identified the top active users based on post counts.
- Analyzed yearly post counts using GROUP BY and HAVING.
- Applied aggregate functions, ORDER BY, and LIMIT.

**4. Joins & Built-in Functions**
- Combined user, post, like, and comment information using joins.
- Calculated total likes and comments for each post.
- Applied UPPER, MONTHNAME, and LENGTH functions.
- Combined users who liked or commented using UNION.

**5. Advanced SQL Operations**
- Created a user-defined function to calculate total likes and comments made by users.
- Used subqueries and CTEs to identify users with above-average follower counts.
- Created a stored procedure to retrieve posts based on a username.

**6. Views & Triggers**
- Created a PostSummary view to display post details, total likes, and total comments.
- Implemented a trigger to automatically insert notification records when a user likes a post.


##📊 **Final Summary & Insights**

This project analyzes social media engagement using MySQL based on sample data containing **5 users, 8 posts, 20 likes, 16 comments, and 5 follower relationships**. Descriptive Analysis: Identified **Varun** as the most active user with 3 posts, followed by **Kala** with 2 posts. Analyzed individual post engagement: Post ID 1 – **"Creating memorable meals"** received 3 likes and 2 comments (5 interactions); Post ID 2 – No caption received 2 likes and 1 comment (3 interactions); Post ID 3 – **"Every song is a piece of my heart"** received 4 likes and 3 comments (7 interactions); Post ID 4 – **"Healthy habits, happy life"** received 2 likes and 2 comments (4 interactions); Post ID 5 – **No caption** received 1 like and 1 comment (2 interactions); Post ID 6 – **"deleciuos dinner"** received 2 likes and 2 comments (4 interactions); Post ID 7 – **"Melody hits"** received 3 likes and 2 comments (5 interactions); and Post ID 8 – **"AR Rahman hits"** received 3 likes and 3 comments (6 interactions). Diagnostic Analysis: Identified that Post ID 3 generated the highest engagement with 7 interactions, followed by Post ID 8 with 6 interactions, whereas Post ID 5 recorded the lowest engagement with 2 interactions, highlighting variations in user interactions across posts. Predictive Analysis: Posts receiving higher likes and comments may have the potential to attract more interactions in the future, while posts with lower engagement may require improvements in content. Active users with consistent posting activities may continue to contribute to overall engagement. Prescriptive Analysis: Encourage users to publish engaging and relevant content regularly, improve interaction through likes and comments, and focus on improving posts with lower engagement. Monitor active users and follower activities to strengthen user participation and overall social media engagement.
